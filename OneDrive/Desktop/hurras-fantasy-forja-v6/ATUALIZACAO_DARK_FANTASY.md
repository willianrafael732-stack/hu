# Hurras Fantasy - Atualizacao Dark Fantasy

## O que mudou

- Ficha reconstruida em codigo com 2 paginas A4 fixas.
- Impressao/PDF com `print-color-adjust: exact` para preservar o fundo escuro.
- Visual dark fantasy/soulslike: ferro, cinza, ouro envelhecido, sangue seco e brasas.
- Arsenal ampliado de 19 para 62 armas catalogadas.
- Cada arma possui categoria, raridade, atributo, requisito, bonus, penalidade e classes permitidas.
- Compatibilidade de armas sincronizada automaticamente com cada classe.
- Armaduras ampliadas de 3 para 8 e escudos de 3 para 6.
- Grimorio original mantido.
- 54 novas magias adicionadas, 6 para cada escola: Fogo, Agua, Vento, Terra, Raio, Veneno, Mental, Sombrio e Sagrado.
- Criador de ficha ganhou escola magica, magias/tecnicas conhecidas e passivas adicionais.
- Arsenal permite mandar classe + arma diretamente para a ficha.
- Pagina de racas e classes recebeu paleta dark fantasy integrada ao novo visual.

## Como gerar PDF

1. Abra `funcoes/clan.html`.
2. Monte o personagem.
3. Clique em `Gerar PDF / Imprimir`.
4. Escolha `Salvar como PDF`.
5. Para maxima fidelidade visual, mantenha a opcao de graficos de fundo ativada quando o navegador oferecer essa opcao.

A ficha foi dimensionada para duas paginas A4 sem uma terceira pagina de sobra.
